# Фигуры на плоскости
## Что это

Программа, которая работает с фигурами на плоскости: точка, отрезок, окружность,
прямоугольник, многоугольник и группа фигур.

Для фигур можно посчитать периметр и площадь, найти ограничивающий прямоугольник,
сдвинуть, повернуть и масштабировать их, а также проверить, лежит ли точка внутри фигуры.

Дополнительно сделано:
- пересечение двух отрезков;
- выпуклая оболочка набора точек.

## Как запустить

mvn test                              # тесты
mvn package                           # сборка
java -jar target/figures-1.0.0.jar    # запуск демонстрации
Нужны JDK 21 и Maven.

## Структура

- src/main/java/figures — код программы
- src/test/java/figures — тесты
- Main.java — демонстрация работы всех операций
